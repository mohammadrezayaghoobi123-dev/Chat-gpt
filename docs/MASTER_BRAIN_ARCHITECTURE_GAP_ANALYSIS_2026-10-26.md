## ۱. تعریف طبقه‌ها
- **VE** — Verified existing: پیاده‌سازی و رفتار مرتبط مستقیماً خوانده یا آزموده شده.
- **PI** — Partially implemented: کد هست، رفتار/یکپارچگی لازم ناقص است.
- **DO** — Documented only: طراحی هست، پیاده‌سازی عملیاتی نه.
- **MI** — Missing: پیاده‌سازی کافی شناسایی نشد.
- **BL** — Blocked: وابستگی/محدودیت مشخص مانع است.

## ۶. طرح ارزیابی مرحله‌ای جزیره‌ها (بدون ادعای آستانه‌های استاندارد)

اصل: **هیچ آستانهٔ عددی به‌عنوان استاندارد معرفی نمی‌شود.** آستانه‌ها پس از یک اجرای پایه (baseline) روی همان داده و با قید «تعیین‌شده توسط مالک» ثبت می‌شوند؛ دلیل: سنجه‌های خودساخته بدون پایه، دقت کاذب می‌سازند.

| بُعد | پایلوت پیشنهادی: زیست‌پزشکی/PubMed (تنها منبع واقعی) |
|---|---|
| وظایف | ۲۰–۳۰ پرسش با پاسخ‌های بازبینی‌شدهٔ انسانی (مثلاً وجود/عدم وجود شواهد برای یک گزارهٔ مشخص)؛ تعداد را مالک تأیید می‌کند |
| منبع و منشأ | هر ادعا به PMID و تاریخ دریافت؛ بررسی خودکار: PMID واقعاً وجود دارد و عنوان/چکیده با ادعا مرتبط است |
| درستی ارجاع | نسبت ادعاهایی که ارجاع‌شان قابل‌بازیابی و معتبر است؛ ارجاع ساختگی = شکست سخت |
| تناقض/شاهد مخالف | مجموعهٔ منفی: پرسش‌هایی که شواهد متناقض دارند؛ سامانه باید «مورد اختلاف» گزارش کند نه حکم قطعی |
| بازتولیدپذیری | اجرای مجدد با همان داده ⇒ همان ارجاع‌ها (با ثبت نسخهٔ مدل/پرس‌وجو) |
| عدم‌قطعیت | گزارش صریح محدودیت؛ کالیبراسیون فقط وقتی سنجیدنی است که برچسب حقیقت مستقل داشته باشیم |
| شرط شکست | هر ارجاع ساختگی؛ هر «تأیید» بدون شاهد مستقل؛ هر ادعای قطعی روی شواهد متناقض |
| نگهداری نتایج | رویداد در زنجیرهٔ ممیزی + فایل نتیجه با digest |
| محدودیت‌ها | ارزیابی یک دامنه به دامنه‌های دیگر تعمیم داده نمی‌شود؛ PubMed فقط چکیده/فراداده است نه حقیقت علمی |

دامنه‌های صنعت، اقتصاد/بازار، حسابداری و دانش عمومی هرکدام ارزیابی جدا با منابع و روش خودشان می‌خواهند (مثلاً حسابداری: بازتولید محاسبه از اسناد؛ بازار: عدم‌قطعیت و داده‌های منقضی)؛ **هیچ‌کدام اکنون ارزیابی نشده‌اند.**

## ۷. تناقض‌ها و محدودیت‌های شناخته‌شدهٔ این گام
1. `ctp_runner` بازاجرا را روی همان میزبان انجام می‌دهد: جداسازی هویت/کلید/فرایند هست، **استقلال محیط نیست**.
2. تأییدکنندهٔ انسانی تنها همان مالک است؛ اگر کلید یا حساب او به خطر بیفتد، سیستم اجازهٔ اجرای هر آزمون ثبت‌شده را می‌دهد (نه کد دلخواه).
3. آزمون‌های ثبت‌شده فقط خودآزمایی پلتفرم‌اند؛ PASS آن‌ها هیچ ادعای علمی دربارهٔ جهان را اثبات نمی‌کند.
4. Cloudflare «Workers Builds» طبق تصمیم مالک خارج از دامنه است و بررسی نشده.
5. ادعای production برای هیچ بخشی مجاز نیست (بخش ۸ راهنمای عملیاتی).
